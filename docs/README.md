# Buurekrom
<p align="center">
  <img src="../frontend/public/buurekrom.svg" alt="Buurekrom Logo" width="100">
</p>

Buurekrom solves the problem that farmers have difficulties finding a path to a field which is possible
to pass with wide machines.

## Beta access

Set `BETA_PASSWORD` in the backend environment to the shared password given to
current testers. For local development,
load `.env` into the backend process environment (see `.env.example`).
